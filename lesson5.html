5.1 什么是数据可视化

把数字、类别等抽象信息转化为视觉元素，让人类的大脑能够快速感知规律、趋势和异常。

5.1.1 图形属性（视觉元素）

在图中画一个点，这个点可以拥有以下属性：

  • 位置（x、y 坐标）
  • 形状（圆、三角、方块等）
  • 大小
  • 颜色（填充色、边框色）
  • 透明度（alpha）
  • 线宽 / 线型（用于线图）

5.2 宏包 ggplot2

ggplot2 是 R 中最流行的绘图包，2024 年 CRAN 下载量已超过 16717239 次。它由 RStudio 首席科学家 Hadley Wickham 在 2005 年博士期间开发。

ggplot2 的图形语法

ggplot2 的核心思想是 图形语法（Grammar of Graphics）：

一张统计图形 = 数据 → 几何对象（geom） → 图形属性（aes） 的映射

通俗说：把数据的数值映射成点的 位置、颜色、大小 等视觉元素。

ggplot() 的 9 大部件

  • data：数据框（必须）
  • mapping：变量 → 视觉属性的映射（必须）
  • geom：几何形状（如点、线、柱）（必须）
  • stat：统计变换（如计数、平滑）
  • scale：坐标轴、颜色标度
  • coord：坐标系（笛卡尔、极坐标）
  • facet：分面（子图）
  • theme：整体风格
  • output：保存图片

基本代码模板

ggplot(data = <DATA>) + 
  <GEOM_FUNCTION>(mapping = aes(<MAPPINGS>))

先来点小菜

使用 diamonds 数据集绘制克拉数 vs 价格的散点图：

library(ggplot2)
diamonds <- read_csv("lesson1/diamonds.csv")

ggplot(diamonds, aes(x = carat, y = price)) + 
  geom_point()

5.3 基本图表

散点图（geom_point）

ggplot(diamonds, aes(carat, price, color = cut)) + 
  geom_point(alpha = 0.6)

柱状图（geom_bar / geom_col）

# 计数柱状图
ggplot(diamonds, aes(cut)) + 
  geom_bar(fill = "steelblue")

# 数值柱状图
diamonds %>% count(cut) %>% 
  ggplot(aes(cut, n)) + 
  geom_col(fill = "darkorange")

直方图（geom_histogram）

ggplot(diamonds, aes(price)) + 
  geom_histogram(bins = 30, fill = "lightgreen", color = "black")

5.4 图表自定义

主题（theme）

ggplot(diamonds, aes(carat, price)) + 
  geom_point() + 
  theme_minimal()

标签（labs）

ggplot(diamonds, aes(carat, price)) + 
  geom_point() + 
  labs(title = "钻石价格与克拉数关系",
       x = "克拉数 (carat)",
       y = "价格 (USD)")

颜色（scale_*）

ggplot(diamonds, aes(carat, price, color = clarity)) + 
  geom_point() + 
  scale_color_brewer(palette = "Set1")
