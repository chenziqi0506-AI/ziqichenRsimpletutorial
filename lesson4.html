课程目标

本课程介绍 R 中的统计分析（方差分析）与线性回归，涵盖数据导入、缺失值检查、变量统计和模型构建。本课程使用 wages 数据集（收入、身高、教育水平等）进行回归分析和单因素方差分析，ToothGrowth 数据集进行双因素方差分析。wages 数据集下载：点此下载。

1. Tidy 统计分析

方差分析（ANOVA）帮助我们比较不同组的平均值是否相同，比如男性和女性的收入是否不同。以下介绍 ANOVA 的步骤：事前检验、单因素 ANOVA、双因素 ANOVA 和事后检验。

1.1 事前检验

在做 ANOVA 之前，需要检查数据是否适合分析。两个简单的事前检验是：

  • 正态性：检查每组数据是否接近正态分布（类似钟形曲线）。我们用 shapiro.test() 检查。
  • 方差齐性：检查各组数据的波动（方差）是否相似。我们用 car::leveneTest() 检查。

示例：用 wages 数据集检查性别对收入的影响。

library(dplyr)
library(car)
wages <- read_csv("lesson4/data/wages.csv")
# 正态性检验
wages %>% group_by(sex) %>% summarise(p_value = shapiro.test(earn)$p.value)
# 方差齐性检验
leveneTest(earn ~ sex, data = wages)

如果 p 值大于 0.05，说明数据通过正态性或方差齐性检验，适合做 ANOVA。如果不通过，可以尝试其他方法（比如非参数检验）。

1.2 单因素方差分析

单因素 ANOVA 用于比较一个分类变量（比如性别）的多组平均值（比如收入）。我们用 aov() 函数分析。

示例：检查 wages 数据集中男性和女性的收入是否不同。

library(broom)
anova_result <- aov(earn ~ sex, data = wages)
summary(anova_result)
# 用 tidyverse 格式输出
anova_result %>% broom::tidy()

如果 p 值小于 0.05，说明性别组之间的收入平均值有显著差异。

1.3 双因素方差分析

双因素 ANOVA 用于同时分析两个分类变量的影响。我们用 ggpubr::ToothGrowth 数据集，包含豚鼠的牙齿长度（len）、喂食方法（supp：橙汁或维生素 C）和剂量（dose：0.5、1、2 mg）。

问题：喂食方法和剂量是否影响牙齿长度？

library(ggpubr)
library(dplyr)
my_data <- ToothGrowth %>%
  mutate(across(c(supp, dose), ~ as_factor(.x)))
head(my_data)
# 双因素 ANOVA
anova_result <- aov(len ~ supp + dose, data = my_data)
anova_result %>% broom::tidy()

检查交互效应（喂食方法和剂量的组合是否影响牙齿长度）：

anova_interaction <- aov(len ~ supp * dose, data = my_data)
anova_interaction %>% broom::tidy()

1.4 事后检验

ANOVA 告诉我们组间有差异，但不知道具体哪组不同。事后检验（post-hoc test）用 TukeyHSD() 比较每对组别。

示例：检查 ToothGrowth 数据集中剂量和喂食方法的差异。

aov(len ~ supp + dose, data = my_data) %>%
  TukeyHSD(which = "dose") %>% broom::tidy()
aov(len ~ supp + dose, data = my_data) %>%
  TukeyHSD(which = "supp") %>% broom::tidy()

结果中的 p 值小于 0.05 表示对应组别之间的平均值差异显著。

2. 线性回归

本节使用 1994 年收集的 wages 数据集（1379 个观测，包含收入、身高、教育水平等信息）进行线性回归分析，探索变量之间的关系。

2.1 数据导入

从本地导入 wages 数据集。

library(readr)
wages <- read_csv("lesson4/data/wages.csv")
head(wages)

2.2 缺失值检查

拿到数据后，先了解变量含义并检查缺失值。wages 数据集的变量包括：

wages %>% colnames()
# 输出: "earn" "height" "sex" "race" "ed" "age"

检查缺失值：

wages %>%
  summarise_all(~ sum(is.na(.)))

2.3 变量简单统计

探索变量分布，例如男女数量、身高和收入均值。

# 男女数量
wages %>% count(sex)
# 按性别分组的身高和收入均值
wages %>%
  group_by(sex) %>%
  summarise(
    n = n(),
    mean_height = mean(height),
    mean_earn = mean(earn)
  )

提出问题供探索：

  • 身高越高的人是否挣钱越多？
  • 男性是否比女性挣得多？
  • 影响收入最大的变量是哪个？
  • 如何判定模型是否良好？

2.4 使用 lm() 函数

lm() 是线性回归的核心函数，常用参数包括：

  • formula：指定模型，如 y ~ x，表示 y 由 x 预测。
  • data：数据框，包含响应变量和解释变量。

示例：用身高预测收入。

mod1 <- lm(earn ~ height, data = wages)
names(mod1)
print(mod1)
summary(mod1)
# 查看拟合值
wages %>% modelr::add_predictions(mod1)
# 查看残差
wages %>%
  modelr::add_predictions(mod1) %>%
  modelr::add_residuals(mod1)

2.5 多元线性回归

扩展到多个预测变量，例如身高和教育水平。

mod2 <- lm(earn ~ height + ed, data = wages)
print(mod2)
summary(mod2)

2.6 变量重要性

评估哪个变量对收入影响最大。两种方法：

  • 标准化系数：将变量标准化后比较系数绝对值。
  • t 统计量：通过 caret::varImp() 比较 t 值绝对值。
library(dplyr)
library(caret)
fit <- wages %>%
  mutate_at(vars(earn, height, ed, age), scale) %>%
  lm(earn ~ 1 + height + ed + age, data = .)
summary(fit)
caret::varImp(fit)
