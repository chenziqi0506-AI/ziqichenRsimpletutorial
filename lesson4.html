课程目标

本课程介绍 R 中的 Tidy 统计分析（包括方差分析、t 检验、卡方检验）和线性回归，涵盖数据导入、缺失值检查、变量统计和模型构建。本课程使用 wages 数据集（收入、身高、教育水平等）进行回归分析，ToothGrowth 和 mtcars 数据集进行统计分析。wages 数据集下载：点此下载。

1. Tidy 统计分析

Tidy 统计分析利用 tidyverse 工具进行方差分析（ANOVA）、t 检验和卡方检验，根据变量类型和组别数量选择合适方法。

X 变量类型 X 组别数量 Y 变量类型 分析方法 R 语法
定类 2 组或多组 定量 方差分析 aov()
定类 仅 2 组 定量 t 检验 t.test()
定类 2 组或多组 定类 卡方检验 chisq.test()

1.1 单因素方差分析

当解释变量（X）只有一个时，称为单因素方差分析。以下使用 wages 数据集分析性别对收入的影响。

library(dplyr)
library(broom)
wages <- read_csv("lesson4/data/wages.csv")
# t 检验
t.test(earn ~ sex, data = wages)
# 线性模型
lm(earn ~ sex, data = wages) %>% summary()
# ANOVA
aov(earn ~ sex, data = wages) %>% summary()

1.2 双因素方差分析

当有两个解释变量时，称为双因素方差分析。使用 ggpubr 包的 ToothGrowth 数据集，包含 60 个样本，记录豚鼠在不同喂食方法（supp: 橙汁或维生素 C）和剂量（dose: 0.5、1、2 mg）下的牙齿长度（len）。

library(ggpubr)
library(dplyr)
library(broom)
my_data <- ToothGrowth %>%
  mutate(across(c(supp, dose), ~ as_factor(.x)))
head(my_data)
# 双因素 ANOVA
aov(len ~ supp + dose, data = my_data) %>% broom::tidy()
# 多重比较
aov(len ~ supp + dose, data = my_data) %>%
  TukeyHSD(which = "dose") %>% broom::tidy()
aov(len ~ supp + dose, data = my_data) %>%
  TukeyHSD(which = "supp") %>% broom::tidy()
# 检查交互效应
aov(len ~ supp * dose, data = my_data) %>% broom::tidy()

1.3 tidyverse 中的应用

结合 tidyverse 进行分组统计分析，例如对 mtcars 数据集按气缸数（cyl）分组，分析齿轮数（gear）对油耗（mpg）的影响。

library(dplyr)
library(broom)
mtcars %>%
  group_by(cyl) %>%
  summarise(
    broom::tidy(aov(mpg ~ gear, data = cur_data())),
    .groups = "keep"
  ) %>%
  select(term, statistic, p.value) %>%
  filter(term != "Residuals") %>%
  arrange(p.value)

1.4 ggpubr 高级分析

使用 ggpubr 的 anova_test() 进行单因素、双因素和重复测量 ANOVA。

library(ggpubr)
# 单因素 ANOVA
my_data %>% anova_test(len ~ dose)
# 双因素 ANOVA
my_data %>% anova_test(len ~ supp * dose)
# 双因素重复测量 ANOVA
my_data %>%
  mutate(id = rep(1:10, 6)) %>%
  anova_test(dv = len, wid = id, within = c(supp, dose))

2. 线性回归

本节使用 1994 年收集的 wages 数据集（1379 个观测，包含收入、身高、教育水平等信息）进行线性回归分析，探索变量之间的关系。

2.1 数据导入

从本地导入 wages 数据集。

library(readr)
wages <- read_csv("lesson4/data/wages.csv")
head(wages)

2.2 缺失值检查

拿到数据后，先了解变量含义并检查缺失值。wages 数据集的变量包括：

wages %>% colnames()
# 输出: "earn" "height" "sex" "race" "ed" "age"

检查缺失值：

wages %>%
  summarise_all(~ sum(is.na(.)))

2.3 变量简单统计

探索变量分布，例如男女数量、身高和收入均值。

# 男女数量
wages %>% count(sex)
# 按性别分组的身高和收入均值
wages %>%
  group_by(sex) %>%
  summarise(
    n = n(),
    mean_height = mean(height),
    mean_earn = mean(earn)
  )

提出问题供探索：

  • 身高越高的人是否挣钱越多？
  • 男性是否比女性挣得多？
  • 影响收入最大的变量是哪个？
  • 如何判定模型是否良好？

2.4 使用 lm() 函数

lm() 是线性回归的核心函数，常用参数包括：

  • formula：指定模型，如 y ~ x，表示 y 由 x 预测。
  • data：数据框，包含响应变量和解释变量。

示例：用身高预测收入。

mod1 <- lm(earn ~ height, data = wages)
names(mod1)
print(mod1)
summary(mod1)
# 查看拟合值
wages %>% modelr::add_predictions(mod1)
# 查看残差
wages %>%
  modelr::add_predictions(mod1) %>%
  modelr::add_residuals(mod1)

2.5 多元线性回归

扩展到多个预测变量，例如身高和教育水平。

mod2 <- lm(earn ~ height + ed, data = wages)
print(mod2)
summary(mod2)

2.6 变量重要性

评估哪个变量对收入影响最大。两种方法：

  • 标准化系数：将变量标准化后比较系数绝对值。
  • t 统计量：通过 caret::varImp() 比较 t 值绝对值。
library(dplyr)
library(caret)
fit <- wages %>%
  mutate_at(vars(earn, height, ed, age), scale) %>%
  lm(earn ~ 1 + height + ed + age, data = .)
summary(fit)
caret::varImp(fit)
