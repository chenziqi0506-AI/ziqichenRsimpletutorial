课程目标

本课程深入探讨 dplyr 包的统计功能，包括选取或删除变量/个案、更改或新建变量/个案、统计分析、分组统计和数据合并。本课程使用 diamonds 数据集，点此下载。

1. dplyr 选取或删除

我删除了你的微信，本质上是保留了除了你以外所有人的微信。所以删除的本质就是选取。因此，在 tidyverse 里面，选取函数兼具了“保留”（选取）和“删除”的功能。

列命令（选变量）

  • select()：根据位置或名称选取列
  • pull()：根据位置或名称抽取一列，输出矢量格式（进阶技巧）

行命令（选个案）

  • head() 和 tail()：抽取数据的开头或结尾几行
  • slice()：根据位置抽取行
  • filter()：根据变量取值抽取行
  • slice_sample()：随机抽取若干行（进阶技巧）
  • slice_headtail() 和 slice_interval()：根据位置抽取特定行
  • distinct()：去重，保留不重复的个案（进阶技巧）

示例：从 diamonds 数据集选取变量和行。

library(dplyr)
diamonds_subset <- diamonds %>%
  select(carat, cut, price) %>%
  filter(carat > 1) %>%
  slice_head(n = 5)
diamonds_vector <- diamonds %>% pull(price)

2. dplyr 更改或新建

当你添加一个手机号到通讯录，手机会问你是“新建联系人”还是“添加到已有联系人”。这是两个不同的操作。不过，dplyr 的 mutate() 函数，将它们合二为一了。

更改变量名

  • rename()：重命名
  • rename_with()：批量重命名（进阶技巧）

更改或新建列（变量）

  • mutate()：更改、新建变量
  • fill()：就近填充缺失值（进阶技巧）
  • replace_na()：批量替换缺失值（进阶技巧）
  • rownames_to_column()：复制行名称为变量（进阶技巧）
  • add_count()：添加变量频数为新变量（进阶技巧）
  • unite()：合并多个变量为一个（进阶技巧）
  • separate()：拆分一个变量为多个（进阶技巧）
  • add_column()：手动添加变量（几乎不用）

更改或新建行（个案）

  • expand() 和 complete()：根据变量取值的组合扩充个案（进阶技巧）
  • add_row()：手动添加个案（几乎不用）

示例：更改和新建 diamonds 数据集变量。

library(dplyr)
diamonds_modified <- diamonds %>%
  rename(weight = carat) %>%
  mutate(price_per_carat = price / weight,
         high_price = ifelse(price > 10000, "High", "Low"))

3. dplyr 统计

类别变量

  • count()：计算各类别数量

连续变量

  • summarise()：统计个别统计量

示例：统计 diamonds 数据集。

library(dplyr)
diamonds_stats <- diamonds %>%
  count(cut) %>%
  mutate(pct = n / sum(n) * 100)
diamonds_summary <- diamonds %>%
  summarise(mean_price = mean(price, na.rm = TRUE),
            max_carat = max(carat, na.rm = TRUE))

4. dplyr 分组

分组可以做很多事情，但最常用的，肯定还是分组统计。

  • .by：在函数中分组
  • summarise(..., .by)：统计个别统计量
  • mutate(..., .by)：根据分组统计量更改或新建变量
  • group_by()：在函数前构造分组数据
  • ungroup()：取消数据分组

示例：分组统计 diamonds 数据集。

library(dplyr)
diamonds_grouped <- diamonds %>%
  group_by(cut) %>%
  summarise(mean_price = mean(price, na.rm = TRUE),
            count = n()) %>%
  ungroup()
diamonds_by <- diamonds %>%
  summarise(mean_price = mean(price, na.rm = TRUE), .by = cut)

5. dplyr 合并

上下合并

  • bind_rows()：根据位置垂直拼接

左右合并

  • bind_cols()：根据位置水平拼接
  • left_join()：根据 ID 变量匹配，只保留前一个数据的个案
  • right_join()：根据 ID 变量匹配，只保留后一个数据的个案
  • full_join()：根据 ID 变量匹配，保留前后数据的所有个案
  • inner_join()：根据 ID 变量匹配，保留前后数据的共同个案

假装合并，实为筛选（删除）

  • semi_join()：根据 ID 变量匹配，筛选前一个数据中与后一个数据的共同个案
  • anti_join()：根据 ID 变量匹配，删除前一个数据中与后一个数据的共同个案

示例：合并 diamonds 子集。

library(dplyr)
diamonds_subset1 <- diamonds %>% slice_head(n = 10)
diamonds_subset2 <- diamonds %>% slice(5:15)
diamonds_joined <- diamonds_subset1 %>%
  left_join(diamonds_subset2, by = c("carat", "cut", "color"))
